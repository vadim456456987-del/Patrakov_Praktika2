# Patrakov_Praktika2 — практика ПП.02.01

Учебный проект: ASP.NET Core MVC-модуль для импорта каталога электроники из CSV. Товары и результаты хранятся в памяти процесса; после перезапуска приложение начинает с пустого каталога.

## Запуск

Требуется .NET 8 SDK или новее.

```bash
dotnet restore Patrakov_Praktika2.slnx
dotnet run --project src/ECommerceCsvImport/ECommerceCsvImport.csproj
```

Откройте адрес, который напечатает `dotnet run`. Главная страница ведет на форму импорта. Для проверки введите `/csv/sample_products.csv` и нажмите «Импортировать товары». Ожидаемый результат: 11 строк, 11 импортированных товаров, 0 ошибок. Раздел «Каталог» показывает сохраненные в памяти записи.

Форма также принимает CSV-файл с устройства. Поддерживаются UTF-8 CSV, запятые и кавычки внутри полей, пустые значения и экранированные двойные кавычки.

## Проверки

```bash
dotnet test Patrakov_Praktika2.slnx --configuration Release
```

Проект содержит unit-тесты для CSV-парсера, репозитория и сервиса импорта. Проверяются успешная загрузка, заголовки, ошибочные значения, дубликаты SKU, пустые данные, значения варианта «Электроника» и кириллица.

## Формат данных

Обязательные заголовки: `sku,name,description,price,currency,category_name,stock,image_url,is_active,brand,warranty_months,model_number`.

- `sku`, `name`, `price`, `stock`, `is_active`, `brand`, `warranty_months` проверяются;
- цена должна быть больше нуля, остаток — целым неотрицательным числом;
- `is_active`: `true`, `false`, `1` или `0`;
- `brand` обязателен; `warranty_months` — целое от 0 до 60 включительно;
- пустая валюта заменяется на `RUB`, пустая категория — на `Без категории`;
- уже существующий SKU пропускается с ошибкой по номеру строки.

## Структура

- `src/ECommerceCsvImport` — MVC-приложение;
- `tests/ECommerceCsvImport.Tests` — unit-тесты и CSV-фикстуры;
- `Patrakov_Otchet_PP0201_Praktika.docx` — отчет по практике с введением, разделами 1–3, заключением и источниками;
- `Patrakov_Otchet_PP0201_Technical.docx` — технический отчет о задании, архитектуре, CSV-реализации, тестировании и отладке.

Данные не записываются в базу данных и не сохраняются после остановки приложения — это соответствует заданию.
